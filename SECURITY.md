# Security Policy

## Supported Versions

Diffuse-NPU actively provides security updates and vulnerability patches for the latest active release version:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

---

## Reporting a Vulnerability

We prioritize the security and privacy of our users and contributors. If you discover a security vulnerability or sensitive bug in Diffuse-NPU:

1. **Do not create a public issue.**
2. Report your findings via email to [v.parasaran@gmail.com](mailto:v.parasaran@gmail.com) with the subject prefix `[SECURITY] Diffuse-NPU Vulnerability Report`.
3. Include as much information as possible:
   - Vulnerability description and impact.
   - Steps to reproduce, including device model, Android OS version, and model checkpoint if applicable.
   - Proof-of-concept exploit or code snippet, if available.
   - Any proposed remediation or mitigation.

### Response Timeline
- We will acknowledge receipt of your vulnerability report within **48 hours**.
- We will provide an assessment and timeline for remediation within **7 days**.
- Once a fix is verified and deployed, credit will be publicly acknowledged in release notes (unless anonymity is requested).
